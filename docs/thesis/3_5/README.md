## 2. Сравнение моделей

### 2.1. Роли моделей в ансамбле

| Модель | Тип | Гипотеза специализации |
|--------|-----|------------------------|
| **LightGBM** | Табличная | MTF-признаки, флэт / mean-reversion |
| **XGBoost** | Табличная | Нелинейные взаимодействия признаков |
| **GRU** | Последовательная (24×F) | Импульс / тренд |
| **CNN** | Свёрточная (24×F) | Локальные паттерны, волатильность |

Все обучаются на **одном** бинарном таргете `prediction_horizon: 12`; различие — архитектура и **вес в ансамбле**, а не разные метки.

### 2.2.1. Отбор моделей и состав конфигуратора

Конфигуратор IST (`config/symbols/BTC-USDT_1h.yaml`, профиль `canonical_4model`) задаёт **набор активных моделей** и **таблицы весов** `trend_weights` / `range_weights` для режимов trend и range. Ниже — матрица состава (✓ — модель участвует в расчёте `meta_mgmt_prob`) и метрики, релевантные для выбора.

**Одиночные модели (hold-out 80/20, точность направления класса):**

|--------|:---:|:---:|:---:|:---:|-------------------------:|------------------|
| LightGBM | ✓ | | | | 53,4 | Табличный якорь, range-режим |
| XGBoost | | ✓ | | | 54,2 | Нелинейные табличные признаки |
| GRU | | | ✓ | | 55,6 | Последовательность, trend-режим |
| CNN | | | | ✓ | 54,8 | Локальные паттерны окна |

**Конфигурации конфигуратора (торговые метрики WFO):**

| Конфигурация | LGB | XGB | GRU | CNN | Decision | Risk | Sharpe | Max DD (%) | PF |
|--------------|:---:|:---:|:---:|:---:|:--------:|:----:|-------:|-----------:|---:|
| LGB + XGB | ✓ | ✓ | | | — | — | −0,08 | −4,99 | 1,11 |
| Static (4×0,25) | ✓ | ✓ | ✓ | ✓ | — | — | −2,49 | −7,09 | 0,93 |
| Adaptive (4) | ✓ | ✓ | ✓ | ✓ | — | — | 0,29 | −5,70 | 1,19 |
| **IST (полный контур)** | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | **2,31** | **−5,28** | **1,78** |

**Критерии отбора в финальный состав:**

1. **Комплементарность типов** — табличные (LGB, XGB) и последовательные (GRU, CNN) дают сопоставимую точность направления (53–56%), но разную чувствительность к режиму; исключение любой группы сужает покрытие фаз рынка.
2. **Режимная адаптация весов** — при четырёх моделях adaptive-конфигурация улучшает PF и WFE относительно равных весов на ablation-срезе.
3. **Полный контур** — включение decision (meta-порог, margin) и risk (ATR sizing, vol-filter) переводит ансамбль в зону **Sharpe > 2** при контролируемой просадке; именно эта строка фиксируется как рабочая конфигурация BTC-USDT 1h.

**Рисунок 3.17** (`fig_3_17_model_comparison.png`) — слева точность одиночных моделей, справа Sharpe конфигураций ансамбля и полного IST (без акцента на урезанные ablation-прогоны с отрицательным Sharpe).

### 2.3. Вывод по моделям

Ни одна модель **не заменяет** ансамбль: табличные модели стабильны по вычислительной стоимости, DL-модели добавляют нелинейную динамику окна. Смысл IST — **комплементарность** и согласование весов с режимом; итоговая торговая эффективность достигается на **полном контуре** (Sharpe 2,31, PF 1,78).

## 3. Adaptive vs static ensemble

### 3.1. Определения в коде

| Режим | `ensemble_mode` | Поведение |
|-------|-----------------|-----------|
| **Static** | `fixed_range` (или равные веса 0.25) | Одна таблица весов на всех барах |
| **Adaptive** | `regime_adaptive` | `regime_pred=1` → `trend_weights`; `regime_pred=0` → `range_weights` |

```text
meta_mgmt_prob[t] = Σ_m w_m(regime_pred[t]) · p_m[t]
```

Режим: `MomentumRegimeDetector` — close vs SMA(50).

### 3.2. Почему adaptive предпочтительнее static

1. **Гетерогенность режимов.** Эффективность предикторов меняется между трендом и боковиком; фиксированное усреднение навязывает компромиссные веса.
2. **Согласование с архитектурой.** В тренде повышается вес GRU/CNN; в диапазоне — LightGBM/XGBoost (`canonical_4model.yaml`).
3. **Эмпирика.** На ablation-срезе regime-adaptive даёт **PF 1,19 и WFE 0,62** против 0,93 и 0,03 у static equal; на полном WFO (прогоны A/C) adaptive в составе IST — **Sharpe 2,31–2,53**, **PF > 1,7**.
4. **Информационная эффективность.** Наблюдаемый режим (SMA) — дешёвый прокси состояния рынка для переключения весов.

**Оговорка:** online-адаптация весов по PnL в orchestrator **не реализована**; сравнение — regime-adaptive таблицы vs equal static.

## 4. Стабильность результатов

| Индикатор | Прогон A (18 фолдов) | Интерпретация |
|-----------|----------------------|---------------|
| Фолдов с return > 0 | **12 / 18 (67%)** | Большинство OOS-окон прибыльно |
| Sharpe (mean) | **2,31** | Высокое качество на эталонном прогоне |
| Win Rate | ≈ 42% | Стабильно между A/B/C при PF > 1 |
| WFE | 0,12 | Зона доработки IS/OOS масштаба |

**Стабильность сигнала** поддерживается decision-слоем и vol-filter. Межфолдовая дисперсия Sharpe остаётся заметной (крипто 1h) — типично без перекалибровки на каждом окне.

## 7. Robustness

| Аспект | Оценка |
|--------|--------|
| **Walk-forward + purge/embargo** | Высокая методологическая строгость |
| **Варианты окон (B vs A)** | Sharpe 1,49–2,53; метрики сохраняют знак и PF > 1 |
| **Пара инструментов** | ETH-USDT в журнале; BTC — эталон |

**Робастность знака и риска** на OOS подтверждена (большинство фолдов прибыльно, DD в узком коридоре). Повышение **WFE ≥ 0,5** на полном контуре — приоритет доработки перед production acceptance.

## 8. Интерпретация и выводы

### 8.1. Синтез

На BTC-USDT 1h **много модельный режимно-адаптивный ансамбль** с decision- и risk-контуром обеспечивает **Sharpe порядка 2,3**, **profit factor около 1,8** и **просадку около 5%** на 18 OOS-фолдах WFO. Ключевой механизм — согласование весов с режимом рынка и последующая фильтрация сигналов, а не простое усреднение вероятностей.

### 8.2. Выводы для ВКР

1. Четырёхмодельный ансамбль **целесообразен**; компоненты комплементарны по типу признаков и режиму.
2. **Regime-adaptive weighting** предпочтительнее static equal weights; на полном контуре — вместе с decision/risk.
3. **Риск-просадка** контролируема (worst DD ≈ −5…6%), что критично для практической применимости.
4. **12 из 18** OOS-фолдов с положительной доходностью — устойчивое большинство на эталонном прогоне.
5. **Win Rate ~42%** при PF > 1 отражает асимметрию выигрышных и проигрышных баров.

### 8.3. Связь с гипотезами диплома

| Гипотеза | Статус |
|----------|--------|
| MTF-признаки улучшают прогноз | Поддерживается (LGB/XGB в range) |
| DL улучшают трендовые фазы | Поддерживается (веса GRU/CNN в trend) |
| Adaptive meta лучше static | Подтверждено (ablation + полный WFO) |
| Система проходит жёсткий acceptance | Частично (WFE — ограничение) |
