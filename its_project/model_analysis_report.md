### 🔍 Анализ проблем

#### GRU Model проблемы:
1. **Небаланс классов:** Модель научилась предсказывать только класс HOLD (94% данных)
2. **Отсутствие предсказаний для SELL/BUY:** Precision = 0% для экстремальных классов
3. **Переобучение на доминирующий класс:** Модель не научилась определять торговые сигналы

#### Gradient Boosting преимущества:
1. **Хорошая обработка небаланса:** Успешно определяет все классы
2. **Высокая точность:** 99% общая точность
3. **Стабильные предсказания:** Низкое количество ошибок
