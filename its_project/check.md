## 3. Формулы моделей (КРИТИЧНО)

### 📊 Базовые индикаторы

#### SMA:

SMA_t = \frac{1}{n} \sum_{i=0}^{n-1} P_{t-i}

* [ ] описан параметр ( n )
* [ ] объяснено сглаживание

---

#### EMA:

EMA_t = \alpha P_t + (1-\alpha) EMA_{t-1}

* [ ] указано ( \alpha = \frac{2}{n+1} )

---

#### RSI:

RSI = 100 - \frac{100}{1 + RS}

* [ ] ( RS = \frac{AvgGain}{AvgLoss} )

---

#### MACD:

* [ ] ( MACD = EMA_{12} - EMA_{26} )
* [ ] Signal = EMA(MACD)

---

#### Bollinger Bands:

* [ ] ( MA \pm k\sigma )

---

## 5. Метрики оценки (ОБЯЗАТЕЛЬНО)

👉 Модели оцениваются через метрики, а не просто «точность» ([NCBI][1])

---

## ✔ Для классификации

#### Accuracy:

Accuracy = \frac{TP + TN}{TP + TN + FP + FN}

---

#### Precision:

[
Precision = \frac{TP}{TP + FP}
]

---

#### Recall:

[
Recall = \frac{TP}{TP + FN}
]

---

#### F1-score:

[
F1 = 2 \cdot \frac{Precision \cdot Recall}{Precision + Recall}
]

---

#### ROC-AUC:

* [ ] кривая TPR vs FPR
* [ ] устойчива к imbalance ([learn.mathnai.com][2])
