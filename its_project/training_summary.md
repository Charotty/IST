## 🏆 Результаты

### Лучшая модель: Gradient Boosting
- **Accuracy:** 99-100%
- **Преимущества:** 
  - Отличная обработка небаланса классов
  - Высокая точность предсказаний
  - Быстрое обучение (1-2 секунды)
  - Интерпретируемость (важность признаков)

### Слабые стороны GRU
- **Проблема:** Предсказывает только HOLD класс
- **Причина:** Небаланс классов в данных (94% HOLD)
- **Решение:** Балансировка данных, взвешивание потерь

## 🚀 Процесс обучения

### Этапы:
1. **Подготовка данных:** Синтетические данные с 9 техническими признаками
2. **Разделение выборки:** 80% обучающая, 20% тестовая
3. **Настройка гиперпараметров:** Оптимальные параметры для каждой модели
4. **Обучение:** Мониторинг с callback функциями
5. **Валидация:** Расчет метрик и анализ ошибок

### Конфигурация Gradient Boosting:

## 📊 Используемые признаки

1. **RSI** - Индекс относительной силы
2. **MACD** - Схождение/расхождение скользящих средних
3. **BB_Upper/BB_Lower** - Полосы Боллинджера
4. **Volume** - Торговый объем
5. **Price_Change** - Изменение цены
6. **Bid_Ask_Spread** - Спред между покупкой/продажей
7. **Order_Imbalance** - Дисбаланс ордеров
8. **Sentiment** - Сентимент анализа

## 🎯 Торговые сигналы

### Классификация:
- **0 (SELL):** Сигнал на продажу
- **1 (HOLD):** Держать позицию
- **2 (BUY):** Сигнал на покупку

### Правила генерации:
- **BUY:** RSI < 35, Sentiment > 0.3, Price_Change > 0.5%, Order_Imbalance > 0.1
- **SELL:** RSI > 65, Sentiment < -0.3, Price_Change < -0.5%, Order_Imbalance < -0.1
- **HOLD:** Все остальные случаи
