# Руководство по обучению моделей на реальных данных

## 🎯 Ответы на ваши вопросы

### 1. Почему система обучается на синтетических данных?

**Проблема:** Система изначально использовала синтетические данные потому что:
- ❌ Отсутствовала интеграция с реальными биржевыми данными
- ❌ Не было сборщика рыночных данных
- ❌ Тестирование проводилось на изолированных данных

**Решение:** Создан `real_data_collector.py` который:
- ✅ Подключается к реальным биржам (Binance, Bybit) через CCXT
- ✅ Собирает OHLCV данные, order book, технические индикаторы
- ✅ Создает реальные признаки для обучения моделей
- ✅ Генерирует метки (BUY/HOLD/SELL) на основе будущих движений цены

### 2. Почему нельзя запустить GUI и обучать модели в нём?

**Проблема с текущим GUI:**
- ❌ Старый GUI (`gui/main_window.py`) использует симуляцию данных
- ❌ Обучение моделей было реализовано только для симуляции
- ❌ Нет интеграции с реальными данными
- ❌ Модели обучаются на сгенерированных данных

**Решение:** Создан новый `enhanced_gui_trainer.py` который:
- ✅ Собирает реальные данные с бирж
- ✅ Обучает модели на реальных данных
- ✅ Показывает прогресс сбора данных и обучения
- ✅ Сохраняет и загружает обученные модели
- ✅ Сравнивает производительность моделей

## 🚀 Как запустить обучение на реальных данных

### Шаг 1: Установка зависимостей

```bash
pip install ccxt pandas numpy scikit-learn torch PyQt6 joblib
```

### Шаг 2: Запуск нового GUI с обучением

```bash
python enhanced_gui_trainer.py
```

### Шаг 3: Использование GUI

1. **Сбор данных:**
   - Выберите торговую пару (BTC/USDT, ETH/USDT и т.д.)
   - Выберите таймфрейм (1h, 4h, 1d)
   - Укажите количество дней для сбора (30 дней по умолчанию)
   - Нажмите "Собрать реальные данные"

2. **Обучение моделей:**
   - Выберите модели для обучения (Gradient Boosting, GRU, Ensemble)
   - Нажмите "Обучить выбранные модели"
   - Дождитесь завершения обучения

3. **Анализ результатов:**
   - Посмотрите результаты в таблице
   - Изучите сравнение моделей
   - Проверьте важность признаков

4. **Сохранение моделей:**
   - Нажмите "Сохранить обученные модели"
   - Выберите директорию для сохранения

## 🚨 Важные замечания

1. **Качество данных зависит от периода:**
   - Большие периоды = больше данных, но возможны изменения в рынке
   - Маленькие периоды = актуальные данные, но мало для обучения

2. **Разные таймфреймы:**
   - 1h: Краткосрочная торговля, больше шума
   - 4h: Среднесрочная торговля, баланс шума/сигнала
   - 1d: Долгосрочная торговля, меньше шума

3. **Требования к API:**
   - Для больших объемов данных могут потребоваться API ключи
   - Binance имеет rate limits
   - Рекомендуется использовать sandbox для тестирования
