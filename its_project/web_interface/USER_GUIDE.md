# Руководство пользователя ITS (Intelligent Trading System)

## Обзор

ITS - это система для машинного обучения и бэктестинга торговых стратегий на криптовалютных рынках. Система состоит из четырёх основных разделов: Загрузка данных, Инжиниринг признаков, Обучение модели и Бэктестинг/Деплой.

---

## 1. Загрузка данных

### Назначение
Загрузка исторических данных о ценах и объёмах для обучения и тестирования моделей.

### Параметры

**Символ (Symbol)**
- Торговая пара (например, BTC/USDT, ETH/USDT)
- Определяет актив для анализа

**Таймфрейм (Timeframe)**
- Временной интервал свечей:
  - `1m` - 1 минута
  - `5m` - 5 минут
  - `15m` - 15 минут
  - `1h` - 1 час
  - `4h` - 4 часа
  - `1d` - 1 день
- Более короткие таймфреймы дают больше данных, но больше шума
- Более длинные таймфреймы дают меньше данных, но более чёткие тренды

**Диапазон дат**
- Начальная и конечная дата для загрузки данных
- Рекомендуется загружать минимум 3-6 месяцев данных для обучения
- Для intraday стратегий используйте 1-3 месяца
- Для долгосрочных стратегий используйте 6-12 месяцев

**Источники данных**
- OKX REST API - основной источник данных
- Можно выбрать несколько источников для кросс-проверки

## 2. Инжиниринг признаков

### Назначение
Создание технических индикаторов и признаков из сырых данных для обучения модели.

### Признаки и их назначение

**Трендовые индикаторы**
- `SMA_5`, `SMA_20`, `SMA_50` - Простые скользящие средние
  - Показывают направление тренда
  - SMA_5 - краткосрочный тренд
  - SMA_50 - долгосрочный тренд
- `EMA_12`, `EMA_26` - Экспоненциальные скользящие средние
  - Более чувствительны к последним ценам
  - Используются в MACD

**Моментум индикаторы**
- `RSI_14` - Индекс относительной силы
  - Показывает перекупленность (>70) или перепроданность (<30)
  - Диапазон: 0-100
- `MACD` - Схождение/расхождение скользящих средних
  - Показывает силу тренда
  - MACD_line = EMA_12 - EMA_26
  - Signal_line = EMA_9 от MACD_line
- `MACD_signal` - Сигнальная линия MACD
- `MACD_hist` - Гистограмма MACD (разница между MACD и signal)

**Волатильность**
- `BB_upper`, `BB_middle`, `BB_lower` - Полосы Боллинджера
  - Показывают волатильность и возможные развороты
  - middle = SMA_20
  - upper/lower = ±2 стандартных отклонения
- `ATR_14` - Средний истинный диапазон
  - Показывает волатильность рынка
  - Используется для определения стоп-лоссов

**Объём**
- `Volume_SMA_20` - Средний объём за 20 периодов
  - Показывает интерес к активу
  - Высокий объём подтверждает тренд

**Ценовые изменения**
- `Returns_1` - Доходность за 1 период
  - Показывает изменение цены
  - Используется для волатильности

### Рекомендации
- Для трендовых стратегий: SMA, EMA, MACD
- Для контр-трендовых: RSI, Bollinger Bands
- Для волатильности: ATR, Returns
- Начните с всех признаков, затем уберите наименее важные

## 3. Обучение модели

### Назначение
Обучение нейронной сети для предсказания направления движения цены.

### Параметры модели

**Тип модели (Model Type)**
- `LSTM` - Long Short-Term Memory
  - Лучше всего подходит для временных рядов
  - Запоминает долгосрочные зависимости
  - Рекомендуется для начала
- `GRU` - Gated Recurrent Unit
  - Упрощённая версия LSTM
  - Быстрее обучается
  - Менее ресурсоёмкая
- `Transformer` - Attention-based модель
  - Лучше всего для сложных паттернов
  - Требует больше данных
  - Медленнее обучается
- `Ensemble` - Ансамбль моделей
  - Комбинация нескольких моделей
  - Более стабильные предсказания

**Длина последовательности (Sequence Length)**
- Количество предыдущих свечей для анализа
- Диапазон: 10-200
- Рекомендации:
  - Для 1m таймфрейма: 60-120
  - Для 1h таймфрейма: 24-48
  - Для 1d таймфрейма: 20-30
- Больше длина = больше контекста, но медленнее обучение

**Скрытые слои (Hidden Layers)**
- Количество слоёв в нейросети
- Диапазон: 1-4
- Рекомендации:
  - Начните с 2 слоёв
  - Увеличивайте, если модель недообучается
  - Слишком много слоёв может привести к переобучению

**Dropout**
- Регуляризация для предотвращения переобучения
- Диапазон: 0.0-0.5
- Рекомендации:
  - 0.1-0.2 для небольших наборов данных
  - 0.2-0.3 для средних наборов данных
  - 0.3-0.5 для больших наборов данных
- Слишком высокий dropout может недообучить модель

**Скорость обучения (Learning Rate)**
- Шаг оптимизации
- Диапазон: 0.0001-0.01
- Рекомендации:
  - 0.001 - стандартное значение
  - 0.0001 - для точной настройки
  - 0.01 - для быстрого обучения (может быть нестабильно)
- Если loss не уменьшается, уменьшите learning rate

**Эпохи (Epochs)**
- Количество полных проходов по данным
- Диапазон: 10-200
- Рекомендации:
  - 25-50 для быстрого тестирования
  - 50-100 для нормального обучения
  - 100-200 для финального обучения
- Слишком много эпох может привести к переобучению

**Размер батча (Batch Size)**
- Количество примеров за одну итерацию
- Диапазон: 16-128
- Рекомендации:
  - 16-32 для небольших наборов данных
  - 32-64 для средних наборов данных
  - 64-128 для больших наборов данных
- Больше batch size = быстрее обучение, но меньше точность

**Разделение train/test (Train/Test Split)**
- Доля данных для обучения
- Диапазон: 0.5-0.9
- Рекомендации:
  - 0.7-0.8 - стандартное значение
  - 0.9 для больших наборов данных
  - 0.5 для маленьких наборов данных

### Метрики качества

**Accuracy (Точность)**
- Доля правильных предсказаний
- Диапазон: 0-1
- >0.5 - лучше случайного угадывания
- >0.6 - хороший результат
- >0.7 - отличный результат

**Precision (Точность положительных предсказаний)**
- Доля верных положительных предсказаний среди всех положительных
- Важно для минимизации ложных сигналов на покупку

**Recall (Полнота)**
- Доля найденных положительных примеров
- Важно для минимизации пропущенных возможностей

**F1-Score**
- Гармоническое среднее precision и recall
- Балансирует precision и recall
- >0.6 - хороший результат

### Рекомендации по настройке
1. Начните с LSTM, sequence_length=60, hidden_layers=2, dropout=0.2, lr=0.001, epochs=50
2. Если accuracy < 0.5:
   - Увеличьте sequence_length
   - Уменьшите learning rate
   - Добавьте больше данных
3. Если accuracy > 0.7 на train, но < 0.5 на test:
   - Увеличьте dropout
   - Уменьшите количество слоёв
   - Уменьшите epochs

## 4. Бэктестинг

### Назначение
Проверка обученной модели на исторических данных для оценки потенциальной прибыльности.

### Параметры

**Порог входа (Entry Threshold)**
- Минимальная вероятность для открытия позиции
- Диапазон: 0.5-0.9
- Рекомендации:
  - 0.6-0.7 для умеренной стратегии
  - 0.7-0.8 для консервативной стратегии
  - 0.8-0.9 для очень консервативной стратегии
- Выше threshold = меньше сделок, но выше точность

**Порог выхода (Exit Threshold)**
- Вероятность для закрытия позиции
- Диапазон: 0.3-0.6
- Рекомендации:
  - 0.4-0.5 - стандартное значение
  - Должен быть ниже entry threshold

**Стоп-лосс (Stop Loss)**
- Максимальный убыток в процентах
- Диапазон: 1-10%
- Рекомендации:
  - 1-2% для intraday
  - 2-5% для swing
  - 5-10% для долгосрочных

**Тейк-профит (Take Profit)**
- Целевая прибыль в процентах
- Диапазон: 1-10%
- Рекомендации:
  - Должен быть в 2-3 раза больше stop loss
  - 2-4% для intraday
  - 5-10% для swing

**Размер позиции (Position Size)**
- Доля капитала на одну сделку
- Диапазон: 1-20%
- Рекомендации:
  - 1-5% для консервативной стратегии
  - 5-10% для умеренной стратегии
  - 10-20% для агрессивной стратегии

### Метрики бэктестинга

**Общая доходность (Total Return)**
- Общая прибыль/убыток в процентах
- Положительное значение = прибыльная стратегия

**Коэффициент Шарпа (Sharpe Ratio)**
- Доходность с учётом риска
- >1 - хороший результат
- >2 - отличный результат
- <0 - стратегия убыточна

**Максимальная просадка (Max Drawdown)**
- Максимальное падение капитала
- <10% - низкий риск
- 10-20% - умеренный риск
- >20% - высокий риск

**Win Rate**
- Доля прибыльных сделок
- >50% - хороший результат
- >60% - отличный результат

**Профит-фактор (Profit Factor)**
- Отношение прибыли к убытку
- >1 - прибыльная стратегия
- >2 - хороший результат
- >3 - отличный результат

**Количество сделок**
- Общее количество сделок
- Слишком мало (<10) - недостаточно статистики
- Слишком много (>1000) - возможно переобучение

## 5. Деплой модели

### Назначение
Запуск обученной модели в реальном времени для торговли.

### Параметры

**Модель для деплоя**
- Выберите только что обученную модель или сохранённую модель
- Сохранённые модели можно загрузить из списка

**Режим торговли**
- `Paper` - Пейпер-трейдинг (симуляция без реальных денег)
  - Рекомендуется для тестирования
  - Нет риска потери денег
- `Live` - Реальная торговля
  - Требует настроенные API ключи
  - Риск потери реальных денег

**Размер позиции (%)**
- Доля капитала на одну сделку
- Рекомендации:
  - Начните с 1-5%
  - Увеличивайте только при успешной работе

**Максимальный дневной убыток (%)**
- Автоматическая остановка при достижении убытка
- Рекомендации:
  - 2-5% для консервативной торговли
  - 5-10% для умеренной торговли

### Мониторинг

**Текущая цена**
- Последняя цена актива

**Текущий сигнал**
- 0 - HOLD (держать)
- 1 - BUY (покупать)
- 2 - SELL (продавать)

**Открытые позиции**
- Количество текущих позиций

**PnL**
- Прибыль/убыток в процентах

---

## Общие рекомендации

1. **Начните с пейпер-трейдинга** - тестируйте стратегии без риска
2. **Используйте достаточное количество данных** - минимум 3-6 месяцев
3. **Не переобучайте модель** - следите за разницей между train и test метриками
4. **Диверсифицируйте** - используйте несколько активов и стратегий
5. **Следите за рисками** - используйте стоп-лоссы и лимиты позиций
6. **Тестируйте регулярно** - рынки меняются, модели нужно переобучать
7. **Начинайте с малого** - небольшие размеры позиции и капитала

## Типичные проблемы и решения

### Проблема: Accuracy ~0.5 (случайное угадывание)
**Решения:**
- Увеличьте количество данных
- Попробуйте другой тип модели
- Измените параметры (sequence_length, learning_rate)
- Добавьте больше признаков
- Измените целевую переменную (threshold)

### Проблема: Loss не уменьшается
**Решения:**
- Уменьшите learning rate
- Увеличьте количество эпох
- Проверьте нормализацию данных
- Упростите модель (меньше слоёв)

### Проблема: Переобучение (высокий train accuracy, низкий test accuracy)
**Решения:**
- Увеличьте dropout
- Уменьшите количество слоёв
- Уменьшите количество эпох
- Добавьте больше данных
- Используйте регуляризацию

### Проблема: Бэктест убыточный
**Решения:**
- Измените пороги входа/выхода
- Настройте стоп-лосс и тейк-профит
- Уменьшите размер позиции
- Попробуйте другой таймфрейм
- Улучшите модель (больше данных, лучшие признаки)
