## 1. Direction (Classification) - Классификация направления

### Предыдущая реализация

**Базовый подход:**
- Фиксированный порог: 0.0015 (0.15%)
- Простое разделение на 3 класса: SELL (0), HOLD (1), BUY (2)
- Линейная классификация без учета рыночной динамики

```python
# Старый код
labels = np.ones(len(returns), dtype=int)
labels[returns < -threshold] = 0  # SELL
labels[returns > threshold] = 2   # BUY
# HOLD = 1
```

### Новая улучшенная реализация

#### Ключевые улучшения:

**1. Адаптивные пороги (Adaptive Thresholds)**
- Динамическая адаптация порогов на основе волатильности
- Учет rolling volatility за последние 20 периодов
- Более высокие пороги в периоды высокой волатильности

```python
# Расчет адаптивных порогов
adaptive_thresholds = np.ones(n) * threshold
for i in range(volatility_window, n):
    recent_returns = returns[i-volatility_window:i]
    recent_vol = np.std(recent_returns)
    adaptive_thresholds[i] = threshold * (1 + recent_vol / 0.01)
```

**2. Моментум-ориентированная классификация**
- Анализ предыдущего возврата для определения тренда
- Различение продолжения тренда и разворота
- Учет инерции движения цены

**3. Многофакторный подход**
- Комбинация текущего возврата и предыдущего
- Учет волатильности для принятия решений
- Интеллектуальная обработка малых движений

**4. Защита от выбросов**
- Игнорирование незначительных движений при низкой волатильности
- Сохранение предыдущего тренда при очень низкой активности

#### Новая логика классификации:

```python
# Enhanced classification with momentum consideration
for i in range(n):
    if i > 0:
        prev_return = returns[i-1]
        current_return = returns[i]
        current_threshold = thresholds[i]
        
        if current_return < -current_threshold:
            # Сильный отрицательный сигнал
            if prev_return < -current_threshold * 0.5:  # Продолжение downtrend
                labels[i] = 0  # SELL
            else:
                labels[i] = 1  # HOLD (возможный разворот)
        elif current_return > current_threshold:
            # Сильный положительный сигнал
            if prev_return > current_threshold * 0.5:  # Продолжение uptrend
                labels[i] = 2  # BUY
            else:
                labels[i] = 1  # HOLD (возможный разворот)
        else:
            # Небольшое движение - учет волатильности
            if abs(current_return) > current_threshold * 0.3:
                labels[i] = 1  # HOLD
            else:
                # Очень низкая волатильность - сохранение тренда
                if i > 1:
                    labels[i] = labels[i-1]
                else:
                    labels[i] = 1  # HOLD
```

### Преимущества новой реализации:

1. **Адаптивность**: Система подстраивается под текущие рыночные условия
2. **Точность**: Учет момента улучшает качество сигналов
3. **Стабильность**: Меньше ложных сигналов в периоды низкой волатильности
4. **Реалистичность**: Лучше отражает реальную торговую логику

## 2. Δreturn (Regression) - Прогнозирование изменения цены

### Предыдущая реализация

**Базовый подход:**
- Простые процентные изменения цены
- Расчет: `(close[i+1] - close[i]) / close[i]`
- Без учета внутридневной волатильности и объемов

```python
# Старый код
returns = np.zeros(n - 1)
for i in range(n - 1):
    returns[i] = (closes[i + 1] - closes[i]) / closes[i]
```

### Новая улучшенная реализация

#### Ключевые улучшения:

**1. Комбинированный расчет возвратов**
- **Log Returns (40%)**: Более симметричные статистические свойства
- **Range-Adjusted Returns (30%)**: Учет внутридневной волатильности
- **VWAP Returns (30%)**: Взвешенные по объему средние цены

**2. Статистическая робастность**
- Логарифмические возвраты для лучшего распределения
- Защита от экстремальных выбросов
- Клиппинг на уровне 5% для снижения шума

**3. Учет рыночной микроструктуры**
- Volume-Weighted Average Price (VWAP)
- Типичная цена (H+L+C)/3
- Корректировка на диапазон цен (High-Low)

#### Новый алгоритм расчета:

```python
# Enhanced return calculation with multiple methods
for i in range(n - 1):
    # Базовый возврат цены
    basic_return = (closes[i + 1] - closes[i]) / closes[i]
    
    # Логарифмический возврат (более симметричный)
    log_return = np.log(closes[i + 1] / closes[i])
    
    # Возврат с корректировкой на диапазон (учет волатильности)
    range_adjustment = (highs[i] - lows[i]) / closes[i]
    adjusted_return = basic_return / (1 + range_adjustment)
    
    # Возврат на основе VWAP
    if volumes[i] > 0:
        typical_price = (highs[i] + lows[i] + closes[i]) / 3
        vwap_return = (typical_price - closes[i]) / closes[i]
    else:
        vwap_return = basic_return
    
    # Взвешенная комбинация
    enhanced_return = 0.4 * log_return + 0.3 * adjusted_return + 0.3 * vwap_return
    
    # Защита от выбросов
    if abs(enhanced_return) > 0.05:  # Клиппинг на 5%
        enhanced_return = np.sign(enhanced_return) * 0.05
    
    returns[i] = enhanced_return
```

### Преимущества новой реализации:

1. **Статистическая корректность**: Логарифмические возвраты имеют лучшие свойства
2. **Учет волатильности**: Корректировка на диапазон цен
3. **Объемная взвешенность**: VWAP учитывает торговую активность
4. **Защита от шума**: Клиппинг экстремальных значений
